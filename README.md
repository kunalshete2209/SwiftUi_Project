# iTrack – Habit Tracking App

A simple and elegant habit tracking app built with SwiftUI. iTrack helps users build and maintain healthy habits with streak tracking, reminders, and a beautiful UI.

## 🚀 Features
- Create, update, and delete habits
- Daily/weekly habit frequency tracking
- Streak counter
- Local notifications as reminders
- Core Data for offline persistence
- Dark mode support
- Smooth and responsive SwiftUI interface

## 🛠 Tech Stack
- SwiftUI
- Core Data
- UIKit (for notifications and compatibility)
- Local Notifications
- Storyboard (limited)
- Xcode
